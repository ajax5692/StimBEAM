📊 Import Animal Information from Excel

Select multiple Excel files (.xlsx/.xls) or CSV files. The tracker will automatically match animals by Animal ID / Mouse ID / Animal Code and merge information from all files. Existing non-empty values are preserved unless a new file provides a value.
📑
Drag & drop multiple Excel files here
Example: colony.xlsx + cages.xlsx + genotypes.xlsx + birthdates.xlsx
Recognized fields include Animal ID/Code, Mouse ID, Species, Strain/Line, Sex, Date of Birth/DOB, Cage, Baseline Weight, Status, Water Restriction Start Date, and Notes. If the same animal occurs in several files, the rows are merged automatically.
